## 🛠️ Issues diagnosed and resolved

### 1. Prod pages empty (Pharmacy Invoices, Master Billing)
- **Symptom:** lists empty on `13.234.242.13`, but worked on the latest code.
- **Root cause:** live server was serving a **stale `.next` build** (code pulled, never rebuilt) **and** the RDS DB was missing migrations the code required (`add_tally_integration`, `add_gl_billwise_fields`, `add_tally_voucher_type_map`, plus an undocumented `invoices.doctor_id/doctor_name` that had **no migration at all**).
- **Fix:** rebuilt; applied the 3 pending migrations; authored + applied the missing `invoices` migration; `pm2 reload`.

### 2. Lab test edit failed to save
- **Root cause:** `z.string().optional()` on nullable columns rejected `null` (the form submits `null` for blank fields) → `expected string`.
- **Fix:** added `optionalText`/`optionalNumber` preprocessors in `service-master-actions.ts`; friendly duplicate-name error; fixed missing `organizationId` on `createLabTest`.

### 3. Bill print — package / service / doctor
- **Package not shown:** summary mode hid all line items → package name disappeared. → Package now always itemized.
- **Avise "service not visible":** summary hid everything except Package → service bills looked blank. → Now collapses **only Pharmacy**; everything else named.
- **"Dr. senior urologist":** bill fell back to `patient.department` when no appointment. → Now prefers `invoice.doctor_name`, then appointment, never `patient.department`.

### 4. "Deposit" meaning in Collections report
- Clarified: "Deposit" = advances **applied** to bills (a funding source), not a tender. Advance **collection** (real Cash/UPI) wasn't shown.
- **Fix (additive):** added "Advance Deposits Collected" (by tender) + relabeled slice "Deposit Applied". Totals unchanged.
